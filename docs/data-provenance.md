# Data Provenance

All data in `src/lib/engine/data/` is generated by `scripts/curate-data.mjs`
(deterministic, seeded PRNG — same output on every run).

## nations.json — 211 entries

- **Names, codes, confederation, pot tier:** real FIFA member associations
  (211 members as of 2026-10). Codes are FIFA 3-letter codes.
- **Elo ratings:** *synthetic*. Deterministic values drawn from per-pot ranges
  (pot 1: 2050–2200 … pot 5: 1250–1450), then refined so the top 56 by Elo
  form pot 1, the next 56 pot 2, etc. They are plausible but **not** real
  Elo ratings.
- **Colors:** deterministic assignment from a 10-color palette.

## clubs.json — 100 entries

- **Names, leagues:** real clubs from the five major European leagues
  (Bundesliga, Premier League, La Liga, Serie A, Ligue 1 — 20 clubs each).
- **Elo ratings:** *synthetic*, drawn from per-league ranges.

## players.json — 1,120 entries

- **Names:** *synthetic composites* generated from per-nation name pools.
  They are **not** real persons.
- **Nation / WC year / position / rating:** deterministic synthetic values.
  Ratings range 62–95 with a small boost for later World Cups.
- **Eligibility:** position-based (GK → GK; DEF → DEF/MID; MID → MID/FWD;
  FWD → FWD).

## Snapshot

All data is labeled `snapshot: "as of 2026-10"`. Regenerate with:

```bash
node scripts/curate-data.mjs
```
